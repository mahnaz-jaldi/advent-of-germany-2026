# LinkedIn post template

```
[Hook: the problem in one sentence, from the job seeker's point of view]

🎄 Door {N}/24: {Tool name}

The problem: {one or two sentences, concrete}

What I built:
→ Input: {what you give it}
→ {AI step, in plain words}
→ Output: {what you get}

The part that matters: {technique}.
I tested it on {n} real {cases}: {score v1} → {final score} after {k} iterations.
What still fails: {one honest limit}

What I learned today: {one line}

Try it: link in the first comment 👇
Built with {tools}. All 24 tools: {repo link}

{Question to the reader, e.g. "Which German rule still confuses you?"}

#LifeInGermany #AIAutomation #{topic}
```

## Rules
- First 2 lines decide if people click "see more": problem first, not "Day 7!".
- One number per post (score, minutes saved, cost per run).
- One honest limit: it builds trust.
- 30-second screen recording or 1 screenshot; no slides needed.
- Test the link in the post vs in the first comment and keep what works for you.
- Reply to every comment in the first hour.

## Kick-off post (30 Nov)
Hook: the everyday things that are hard about life in Germany → what the calendar is → the rule (no tool a single prompt could replace) → what you will measure → follow + repo link.

## Finale post (24 Dec)
Results table of all doors, 3 lessons, the most-used tool, thank-you, what is next (including that you are open to roles in marketing automation / AI / quality).
